# 修仙脚本工具 · 本地工作台（Tabbit 接入）

在原有修仙 `run.py` 自动化脚本之外，套了一个本机 Web 工作台，分四个标签页：
**脚本 / 日常 / 仙榜 / 活动**。

## 目录结构

```
dashboard/
├── server.py              # 零依赖 Python 标准库后端（http.server）
├── config.json            # 本机路径配置（模拟器 ADB、修仙目录、Tabbit 数据、GitHub 仓库）
├── 启动工作台.bat          # 一键启动后端并打开浏览器
├── data/
│   └── project_tasks.json # 修仙分步任务进度快照（日常页展示）
└── static/
    ├── index.html         # 四标签页面骨架
    ├── style.css          # 浅色主题样式
    └── app.js             # 前端逻辑（标签切换、配置列表、运行轮询、任务渲染）
```

## 本地启动

依赖：本机已装 Python 3.10+（无第三方包）。

方式一：双击 `启动工作台.bat`

方式二：命令行
```
python server.py
```
然后浏览器打开 `http://127.0.0.1:8765`

## 标签页说明

- **脚本**：复刻原安卓端界面（状态区、游戏下拉、扫描/安装包库/账号管理按钮、运行日志）；下方为电脑端 runner 分步配置列表，可选择配置、设置循环次数/速度、运行并实时查看日志。
- **日常**：上半部分读取 Tabbit 浏览器同步数据（LevelDB）中的任务/对话标题；下半部分展示修仙分步项目任务进度。
- **仙榜 / 活动**：占位界面，具体任务后续补充。

## 后端接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/status` | 设备/游戏状态（屏幕尺寸走 ADB，其余为占位默认值） |
| GET | `/api/scripts` | 扫描修仙日常分步配置，返回步数、已用/缺失模板 |
| POST | `/api/run` | 拉起 `run.py` 运行指定配置，body：`{config, loops, speed, probe, shot}` |
| GET | `/api/run/<jobid>` | 查询运行状态与日志尾 |
| GET | `/api/tasks` | 解析 Tabbit 浏览器 LevelDB 任务标题（UTF-8 清洗去噪） |
| GET | `/api/project-tasks` | 读取 `data/project_tasks.json` |
| GET | `/api/github` | 返回已接通的 GitHub 仓库信息 |

## 边界与说明

- 后端只监听 `127.0.0.1`，仅连接本机雷电模拟器与本机文件，代码与配置中不含账号凭据。
- `config.json` 内的路径为本机路径，换机器后需按实际目录修改。
- 安卓端功能（扫描并选择游戏、安装包库、账号管理）在电脑工作台内暂为占位按钮，需在对应安卓端实现。
- 本目录只是工作台代码；真正的修仙 `run.py` 与识别模板位于本机修仙流程目录，不随仓库分发。
